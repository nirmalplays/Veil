    What you still rely on.

    • Intel and NVIDIA hardware.The enclave's privacy is only as good as the chips' confidential-computing features. Their attestation is what gets checked.
    • NEAR AI Cloud's published images.The attestation proves which software runs. Build provenance of those images is listed, but not verified here.
    • The site's relay.It holds the site's API key. This demo's relay runs on ordinary hosting, not in a TEE, and the widget says so. It still only ever carries ciphertext.
    • NEAR testnet.The policy registry is a testnet contract. It's for demos, not real funds.
